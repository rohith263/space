## Run Locally

**Prerequisites:** Node.js (v18+)

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Environment configuration:**
   Copy `.env.example` to `.env` or `.env.local` and set your `GEMINI_API_KEY` if using Gemini capabilities.

3. **Run the app:**
   ```bash
   npm run dev
   ```

4. **Build for Production / Vercel:**
   ```bash
   npm run build
   ```
